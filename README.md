# Skills Drawer/Panel with CRUD

A small Flask application that provides a slide-out skills drawer/panel with full CRUD capabilities. Skills are stored in a local JSON file, so no database setup is required.

## Features

- Slide-out drawer/panel UI
- Create, read, update, and delete skills
- Client-side validation and server-side validation
- Persistent JSON storage
- REST API with JSON responses
- Unit tests for the API

## Project structure

- `app.py` - Flask application and REST API
- `static/index.html` - Drawer/panel markup
- `static/styles.css` - Drawer/panel styling
- `static/app.js` - Frontend CRUD logic
- `tests/test_app.py` - API tests
- `data/skills.json` - Created automatically on first write

## Requirements

- Python 3.9+
- Flask
- pytest (for running tests)

## Setup

```bash
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -r requirements.txt
```

## Run the application

```bash
python app.py
```

Open http://localhost:5000 in your browser and click `Open Skills Drawer`.

## API

| Method | Endpoint | Description |
| --- | --- | --- |
| GET | `/api/skills` | List all skills |
| POST | `/api/skills` | Create a new skill |
| GET | `/api/skills/<id>` | Get a single skill |
| PUT | `/api/skills/<id>` | Update a skill |
| DELETE | `/api/skills/<id>` | Delete a skill |

### Skill fields

- `id` - Unique identifier, generated by the server.
- `name` - Required skill name.
- `category` - Optional category, defaults to `General`.
- `proficiency` - Integer from 1 to 5.
- `description` - Optional free-text description.
- `created_at` - Creation timestamp.
- `updated_at` - Last update timestamp.

### Validation rules

- `name` is required and cannot be empty.
- `proficiency` must be an integer between 1 and 5.
- `category` and `description` are optional.
- Unknown fields are ignored.

## Running tests

```bash
pytest
```

## Configuration

Set the `SKILLS_DATA_DIR` environment variable to change where `skills.json` is stored. The default directory is `data`.
